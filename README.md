# Site Web de Skoura – Maroc

Ce projet présente la région de Skoura, située dans la province de Ouarzazate au Maroc.

Le site permet de découvrir :
- La palmeraie de Skoura.
- Les kasbahs traditionnelles.
- La célèbre Kasbah Amridil.
- Les paysages et le patrimoine de la région.
- Une galerie et une présentation de Skoura.

**Technologies utilisées :**
- HTML
- CSS

**Langues disponibles :**
- Français
- Arabe

Projet réalisé dans le cadre d'un travail universitaire.
